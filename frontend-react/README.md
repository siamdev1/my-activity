# ⚛️ React UI Toolkit & Analytics Dashboard

A modern, high-performance developer dashboard interface built with React 18 and Vite.

## Features
- **Responsive Layout:** Dynamic grid adapting effortlessly from mobile screens to 4K displays.
- **Dark / Light Theme:** Custom CSS variable-based theming with smooth transition curves.
- **Activity Heatmap:** Interactive contribution frequency visualizer.
- **Custom Hooks:** Declarative data fetching (`useFetch`) and persistence-backed theme manager (`useDarkMode`).
- **Glassmorphism Design:** Subtle blurs, frosted glass cards, and modern typography.

## Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev
```

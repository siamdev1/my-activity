A modular developer toolkit for WordPress adding custom post types, custom REST API routes, and WooCommerce enhancements.

== Description ==

This plugin provides core developer utilities including:
* Custom Post Types: Portfolio / Projects with custom taxomomy.
* REST API Endpoints: Secure developer telemetry & stats exposed at `/wp-json/siam/v1/`.
* WooCommerce Filters: Custom checkout fields and optimized badge renderers.

== Installation ==

1. Upload `siam-custom-toolkit` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
